# Implementation Plan: Sent/Received Indicator inside Conversation Thread

We will add a prominent and premium visual indicator to specify if a message was "Sent" or "Received" within the conversation thread view (`GroupedMessagesActivity`).

## Detailed Proposed Changes

### 1. Adapter (`SmsAdapter.java`)
Currently, when `hideSender` is set to `true` (such as in `GroupedMessagesActivity` to hide the repetitive contact name), the top `tvSender` header text view is hidden via `View.GONE`. We will repurpose this existing header view to show the direction of the message:
- Modify `onBindViewHolder()`:
  - If `hideSender` is true:
    - Keep `holder.tvSender` visible (`View.VISIBLE`).
    - If the message is outgoing (`sms.isSent()`): Set the text to `"📤 Sent"` in a styled blue color (`#3498DB`).
    - If the message is incoming: Set the text to `"📩 Received"` in a styled green color (`#2ECC71`).
  - If `hideSender` is false:
    - Maintain the existing logic which displays the sender name, phone number, and sent suffix/group count.
