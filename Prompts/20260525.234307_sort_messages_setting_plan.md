# User Prompt
Add a setting to show individual messages in ascending or descending order of timestamp...
And on individual list, sort messages according to this setting

# Implementation Plan: SMS Sorting Setting and Thread Sorting

We will add a preference setting to display individual messages (messages within a single conversation/thread) in either ascending (oldest first) or descending (newest first) order of their timestamp. We will then update the conversation view (`GroupedMessagesActivity`) to sort these messages dynamically and adjust the initial scroll position accordingly to show the newest messages.

## Detailed Proposed Changes

### 1. Data Model (`SmsModel.java`)
To sort messages accurately by timestamp without relying on string comparison or regex parsing of formatted date strings, we will add a raw epoch timestamp `date` field to the `SmsModel` object.
- Add `private long date;` field (epoch milliseconds).
- Update the constructor to accept `long date` as the last parameter.
- Add `public long getDate()` getter method.

### 2. Repository (`SmsRepository.java`)
- Modify `getAllSms` method where `new SmsModel(...)` is instantiated.
- Pass `dateMillis` (which is already retrieved from the cursor as a `long`) to the new constructor of `SmsModel`.

### 3. Settings Manager (`SettingsManager.java`)
- In `createDefaultSettings()`, add a default value for the sorting order. We will name the setting key `sort_ascending` and default it to `true` (ascending order, i.e., oldest first, which is standard chat thread behavior).
- Add helper methods:
  - `public static boolean isSortAscending(Context context)` to retrieve the current setting value.

### 4. Settings Layout (`activity_settings.xml`)
- Add a new settings toggle under the "Confirm before deletion" card.
- Use a `SwitchCompat` wrapped inside a `MaterialCardView` for consistent premium layout aesthetics.
- Title: "Show oldest messages first (Ascending)"
- Description: "Toggles between oldest first (Ascending) and newest first (Descending) sorting order for individual message list."

### 5. Settings Controller (`SettingsActivity.java`)
- Bind the new switch view `switchSortAscending`.
- Read the current value from `SettingsManager.isSortAscending(this)` to initialize the state.
- Save the value dynamically to the settings JSON on state change.

### 6. Individual Messages Activity (`GroupedMessagesActivity.java`)
- Retrieve the current sorting setting in `loadGroupedMessages()`.
- Sort the `filtered` list of `SmsModel` objects:
  - If ascending: Sort by `Long.compare(s1.getDate(), s2.getDate())` (ascending) and scroll to the bottom of the list (`filtered.size() - 1`) to show the most recent message.
  - If descending: Sort by `Long.compare(s2.getDate(), s1.getDate())` (descending) and scroll to the top of the list (`0`) to show the most recent message.
- Update the adapter with the sorted list.
