### Settings UI & Preferences
- Modified [SettingsManager.java](file:///x:/Projects_X/0_Active/8_Android_APK/02_Stable/SMS_Reader_APK_GITHUB/app/src/main/java/com/vypeensoft/smsmanager/SettingsManager.java) to set default values for `notification_audio` (true), `notification_visual` (true), and `notification_preview` (true). Added corresponding getter methods.
- Modified [activity_settings.xml](file:///x:/Projects_X/0_Active/8_Android_APK/02_Stable/SMS_Reader_APK_GITHUB/app/src/main/res/layout/activity_settings.xml) to wrap the layout in a `ScrollView` (preventing vertical overflow cuts) and added three toggle cards with `SwitchCompat` elements for the notification preferences.
- Modified [SettingsActivity.java](file:///x:/Projects_X/0_Active/8_Android_APK/02_Stable/SMS_Reader_APK_GITHUB/app/src/main/java/com/vypeensoft/smsmanager/SettingsActivity.java) to bind the switches, save their values on check changes, and request notification permission on Android 13+ when enabled.

### Runtime Permissions
- Modified [MainActivity.java](file:///x:/Projects_X/0_Active/8_Android_APK/02_Stable/SMS_Reader_APK_GITHUB/app/src/main/java/com/vypeensoft/smsmanager/MainActivity.java) to check for and request the `POST_NOTIFICATIONS` permission automatically at startup on Android 13+ (API 33+).

### Notification Delivery
- Modified [SmsReceiver.java](file:///x:/Projects_X/0_Active/8_Android_APK/02_Stable/SMS_Reader_APK_GITHUB/app/src/main/java/com/vypeensoft/smsmanager/SmsReceiver.java) to check if the app is default SMS app.
  - If default: sends the notification on `SMS_DELIVER` (saving to provider and notifying).
  - If not default: sends the notification on `SMS_RECEIVED` (notifying only).
  This prevents duplicate notifications if the app is the default handler.
- Configured 4 separate notification channels dynamically on Oreo+ (API 26+) based on combinations of Audio (ON/OFF) and Visual (ON/OFF) settings. This is necessary because channel attributes cannot be changed once created in Android.
- Supported toggling message preview. If disabled, the notification uses placeholder text ("New Message" / "You have a new message") to hide private sender and body information.
