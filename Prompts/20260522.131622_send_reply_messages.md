# Implementation Plan - SMS Sending & Replying

We will implement full-featured SMS sending and replying functionality in the **SMS Reader** application. The plan covers background message sending, conversation replying (chat-like interface), composing new messages with contact selection, and default SMS app compatibility.

---

## 1. Objectives & Features

- **Send a New SMS (Compose)**:
  - Add a **Floating Action Button (FAB)** in `MainActivity` to open the `ComposeSmsActivity`.
  - Implement a beautiful `ComposeSmsActivity` where users can enter a recipient (or pick from contacts via the system contact picker) and type a message body.
  - Send the message using `SmsManager`.
  - Save the sent message to the system provider (`content://sms/sent`) so it is reflected in the app.

- **Reply to an Existing Conversation**:
  - Add a **Reply Bar** at the bottom of `GroupedMessagesActivity` (thread view).
  - The reply bar will consist of a text input box (`EditText`) and a send button (`ImageButton`).
  - When sending, it will send the message to the thread's sender, save the message to `content://sms/sent`, clear the text box, and refresh the RecyclerView (scrolling to the bottom).

- **Incoming Message Synchronization (`SmsReceiver`)**:
  - Enhance `SmsReceiver` so that when the app is configured as the default SMS app, it correctly writes received SMS messages to `content://sms/inbox`.
  - Send a local broadcast or clear cache to notify active activities (`MainActivity` & `GroupedMessagesActivity`) to refresh in real-time.

- **Request Dynamic Permissions**:
  - Ensure `SEND_SMS` and `READ_CONTACTS` permissions are requested alongside `READ_SMS`/`WRITE_SMS` in `MainActivity`.

---

## 2. Technical Approach & Class Structure

### 2.1 SMS Sending & Database Writing Utility
Add static helper methods to `SmsRepository.java` to:
1. Send an SMS programmatically using `SmsManager`.
2. Write a message manually to the SMS content provider (`content://sms/sent` or `content://sms/inbox`).
3. Handle long messages using multi-part SMS if needed (`SmsManager.sendMultipartTextMessage`).

### 2.2 Compose Screen (`ComposeSmsActivity`)
1. Create `activity_compose_sms.xml` layout featuring:
   - A Recipient input field (`EditText`) with a "Select Contact" icon button (`ImageButton`).
   - A Message input field (`EditText`).
   - A Send button (`Button`).
2. Update `ComposeSmsActivity.java` to:
   - Wire up inputs and handle the contact selection Intent (`Intent.ACTION_PICK` on contacts).
   - Validate recipient number and message body.
   - Send the message using `SmsRepository` and write it to `content://sms/sent`.
   - Return to `MainActivity` or open the thread upon successful send.

### 2.3 Conversation Reply Bar (`GroupedMessagesActivity`)
1. Modify `activity_grouped_messages.xml` to use a `ConstraintLayout` where the `RecyclerView` is constrained to the top of the screen and the bottom of the reply bar, and the reply bar is pinned to the bottom.
2. Implement the sending logic in `GroupedMessagesActivity.java`:
   - Send SMS to the current group recipient (`groupKey` or telephone number).
   - Write to `content://sms/sent`.
   - Clear reply input and reload messages.
   - Auto-scroll the list to the bottom.

### 2.4 Auto-Refresh on Incoming SMS (`SmsReceiver`)
1. Read incoming SMS from `android.provider.Telephony.SMS_DELIVER` (if default SMS app) or `SMS_RECEIVED`.
2. Write to `content://sms/inbox` if received via `SMS_DELIVER`.
3. Invalidate repository cache and send a local broadcast `com.vypeensoft.smsmanager.REFRESH_SMS`.
4. Register a BroadcastReceiver in `MainActivity` and `GroupedMessagesActivity` to automatically reload messages when a new SMS is received.

## 3. UI/UX Refinements

- **Smooth Scrolling**: RecyclerView will smoothly scroll to the bottom when a message is sent or received.
- **Visual Cues**: Add an indicator/tint to the send button when the user starts typing.
- **Contact Selection**: Let the user choose a phone number seamlessly from their address book.

## 4. Implementation Steps

1. **Step 1**: Add SMS sending and database inserting methods to `SmsRepository.java`.
2. **Step 2**: Implement the reply bar in `activity_grouped_messages.xml` and wire up the logic in `GroupedMessagesActivity.java`.
3. **Step 3**: Create `activity_compose_sms.xml` layout and implement `ComposeSmsActivity.java` with a contact picker.
4. **Step 4**: Add the Compose Floating Action Button (FAB) to `activity_main.xml` and handle clicking it in `MainActivity.java`.
5. **Step 5**: Update `MainActivity.java` permissions checklist to include `SEND_SMS` and `READ_CONTACTS`.
6. **Step 6**: Implement `SmsReceiver.java` to handle incoming SMS, write to provider, and broadcast a refresh event.
7. **Step 7**: Listen to the refresh event in `MainActivity` and `GroupedMessagesActivity` to reload messages instantly.
