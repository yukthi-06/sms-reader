# Implementation Plan: Move Delete Button to Sender Name Header as an Icon

We will remove the red "Delete Message" button at the bottom of the individual message screen and place it as a delete icon (`ImageButton` using `ic_menu_delete`) on the right side of the sender's name at the top of the detail screen.

## Detailed Proposed Changes

### 1. Layout (`activity_message_detail.xml`)
- Remove the `<Button android:id="@+id/btnDeleteDetail" ... />` from the bottom of the layout.
- Wrap the `<TextView android:id="@+id/tvDetailSender" ... />` inside a horizontal `<LinearLayout>` with `gravity="center_vertical"`.
- Set the `TextView` `android:layout_width` to `"0dp"` and `android:layout_weight` to `"1"` so it occupies all available space except for the icon on the right.
- Add an `<ImageButton android:id="@+id/btnDeleteDetail"` on the rightmost side with `"@android:drawable/ic_menu_delete"` icon source, tinted red (`#E74C3C`) and styled with borderless selectable background.

### 2. Activity (`MessageDetailActivity.java`)
- Update the view casting for `R.id.btnDeleteDetail` from `android.widget.Button` to `android.widget.ImageButton`.
- Keep the click listener unchanged, retaining full delete/confirmation functionality.
