# Implementation Plan - AndroidManifest Fix

We will resolve the manifest compilation and validation failures by applying standard Android build configurations.

---

## 1. Issues & Resolution Strategy

### 1.1 Duplicated `<receiver>` Element
- **Issue**: Standard Android Manifest merging fails because we declared two distinct `<receiver>` elements pointing to the same class `com.vypeensoft.smsmanager.SmsReceiver`.
- **Resolution**: Merge both `<intent-filter>` declarations into a single `<receiver>` element. A single receiver can register multiple intent filters.

### 1.2 Deprecated `package` Attribute in Manifest
- **Issue**: Modern versions of the Android Gradle Plugin (AGP) require the module namespace to be specified in the module's `build.gradle` file (`android { namespace "..." }`) rather than via the `package` attribute in the source `AndroidManifest.xml`.
- **Resolution**: Remove the `package` attribute from the `<manifest>` element.

---

## 2. Manifest Modifications

### 2.1 Top-level `<manifest>` Tag
Modify:

```xml
<manifest xmlns:android="http://schemas.android.com/apk/res/android"

    android:versionCode="1"
```


### 2.2 Merged Receiver Tag
Modify:
```xml
        <receiver android:name=".SmsReceiver"
            android:permission="android.permission.BROADCAST_SMS"
            android:exported="true">
            <intent-filter>
                <action android:name="android.provider.Telephony.SMS_DELIVER" />
            </intent-filter>
        </receiver>

        <receiver android:name=".SmsReceiver"
            android:exported="true">
            <intent-filter android:priority="999">
                <action android:name="android.provider.Telephony.SMS_RECEIVED" />
            </intent-filter>
        </receiver>
```
To:
```xml
        <receiver android:name=".SmsReceiver"
            android:permission="android.permission.BROADCAST_SMS"
            android:exported="true">
            <intent-filter>
                <action android:name="android.provider.Telephony.SMS_DELIVER" />
            </intent-filter>
            <intent-filter android:priority="999">
                <action android:name="android.provider.Telephony.SMS_RECEIVED" />
            </intent-filter>
        </receiver>
```
*(Note: Because the system broadcasts both `SMS_DELIVER` and `SMS_RECEIVED` events, the `BROADCAST_SMS` permission requirement is fully satisfied by the system sender, allowing both intent-filters to function inside the same receiver).*
