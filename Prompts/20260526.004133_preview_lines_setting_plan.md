# Implementation Plan: SMS Preview Lines Preference Setting

We will add a preference setting to configure the number of preview lines displayed for messages in all list views (such as the main group list and conversation thread list). The setting will default to 3 lines, and users will be able to customize it through the settings panel.

## Detailed Proposed Changes

### 1. Settings Manager (`SettingsManager.java`)
- Define the default value for the `"preview_lines"` setting as `3` in `createDefaultSettings()`.
- Add a helper getter method:
  - `public static int getPreviewLines(Context context)`: Returns the configured number of preview lines (defaulting to `3`).

### 2. Settings Layout (`activity_settings.xml`)
- Add a new controls section for "Preview Lines" under the "Font Size" settings.
- Implement it consistently with the font size UI:
  - Button to decrease preview lines (`btnDecreasePreviewLines`)
  - TextView displaying the current number of preview lines (`tvPreviewLines`)
  - Button to increase preview lines (`btnIncreasePreviewLines`)
- Constrain the number of lines to a reasonable range (e.g., minimum of 1 line, maximum of 10 lines).

### 3. Settings Controller (`SettingsActivity.java`)
- Bind the decrease/increase buttons and the text view.
- Initialize the text view with the current setting value.
- Implement click listeners to dynamically increment or decrement the preference value, save it to the JSON preferences file, and update the display.

### 4. Adapter (`SmsAdapter.java`)
- In `onBindViewHolder()`:
  - When `isExpandedAll` is false (standard list view preview):
    - Retrieve the preview lines setting dynamically: `int previewLines = SettingsManager.getPreviewLines(context);`
    - Apply this value to `holder.tvBody.setMaxLines(previewLines);`
