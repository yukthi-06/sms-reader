# User Prompt
when new sms arives, no notification is shown.
There should be option for 
1> audio notification
2> visual botification(on top of screen) 
3> message preview when home screen pulled from top to bottom

# Goals
Implement configurable notifications when a new SMS is received. The settings will allow users to toggle:
1. Audio notifications (playing a sound vs. silent).
2. Visual notifications (showing heads-up banners at the top of the screen).
3. Message preview (showing sender and body in the notification shade, or a hidden preview).

### Notification Delivery
#### [MODIFY] [SmsReceiver.java](file:///x:/Projects_X/0_Active/8_Android_APK/02_Stable/SMS_Reader_APK_GITHUB/app/src/main/java/com/vypeensoft/smsmanager/SmsReceiver.java)
- Check if the app is the default SMS app using `android.provider.Telephony.Sms.getDefaultSmsPackage(context)`.
- If default, show notifications on `SMS_DELIVER`. If not default, show notifications on `SMS_RECEIVED`.
- Build the notification based on:
  - Channel selection: Create and select one of 4 dynamic channels based on (Audio ON/OFF, Visual ON/OFF).
  - Preview selection: If `isNotificationPreview` is true, set Title to Sender/Contact and Text to Message Body. Otherwise, use placeholder strings (e.g. Title: "New Message", Text: "You have a new message").
  - Trigger notification posting using `NotificationManager`.
