# Prompt:
when I open contacts app and from that app, i use the option to send SMS, it opens this app, but the phone number is not pre-populayed.
Fix it

## Implementation Details

Fixed by updating `ComposeSmsActivity` to handle `ACTION_SENDTO` / `ACTION_SEND` intents.
The `onCreate` method now calls a new `handleIncomingIntent` function which extracts the phone number from the intent data (usually `smsto:1234567890`) and populates the `etRecipient` field. It also checks for `sms_body` or `Intent.EXTRA_TEXT` extras to pre-populate the `etMessageBody` field.
