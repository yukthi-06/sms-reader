# Implementation Plan - Unread Message Badging on App Icon

This plan outlines adding support for a notification badge on the app icon, showing the count of unread SMS messages.

## Proposed Changes

We will introduce a badging library (`ShortcutBadger`) to handle the cross-launcher icon badging. We will also implement a utility method to query the unread count and apply the badge, and hook it up to relevant events in the application lifecycle.

### Build Dependencies

#### [MODIFY] [build.gradle](file:///x:/Projects_X/0_Active/8_Android_APK/02_Stable/SMS_Reader_APK_GITHUB/app/build.gradle)
Add the ShortcutBadger dependency:
`implementation 'me.leolin:ShortcutBadger:1.1.22@aar'`

### SMS Repository / Helpers

#### [MODIFY] [SmsRepository.java](file:///x:/Projects_X/0_Active/8_Android_APK/02_Stable/SMS_Reader_APK_GITHUB/app/src/main/java/com/vypeensoft/smsmanager/SmsRepository.java)
- Add a helper method `updateAppStateBadge(Context context)`:
  - Queries `content://sms/inbox` where `read = 0`.
  - Gets the count of unread messages.
  - Updates the badge on the app icon using `ShortcutBadger.applyCount(context, count)` (or removes the badge if count is 0).
- Call `updateAppStateBadge(context)` inside:
  - `markSmsAsRead(context, messageId)` (after updating DB)
  - `deleteSms(context, messageId, onSuccess)` (after deleting DB)
  - `saveSmsToInbox(context, sender, message, timestamp)` (after inserting DB)
  - `saveSmsToSent(context, recipient, message)` (as cache updates/clears, though sent messages are read, it is good to refresh)

### Activities and Broadcast Receivers

#### [MODIFY] [MainActivity.java](file:///x:/Projects_X/0_Active/8_Android_APK/02_Stable/SMS_Reader_APK_GITHUB/app/src/main/java/com/vypeensoft/smsmanager/MainActivity.java)
- Call `SmsRepository.updateAppStateBadge(this)` in `onResume()` and inside the callback for `loadSms()`. This ensures the badge is up-to-date whenever the user opens the main screen or when a broadcast refresh occurs.

#### [MODIFY] [SmsReceiver.java](file:///x:/Projects_X/0_Active/8_Android_APK/02_Stable/SMS_Reader_APK_GITHUB/app/src/main/java/com/vypeensoft/smsmanager/SmsReceiver.java)
- Call `SmsRepository.updateAppStateBadge(context)` inside `onReceive()` after message receipt handling, to update the badge when a new SMS arrives while the app is in the background or active.
