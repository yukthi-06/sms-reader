# User Prompt
On group level message screen, currently a portion of the message is shown in the list.  To read full message, user has to go into each message and read it.
To solve this, on the top, keep a button (or icon) to show full message.
When user clicks on this button or icon, all messages in the group view list should be expanded to show full message.
This could be a toggle so that it can be collapsed also

# Implementation Plan: Expand/Collapse All Group Messages

We will add a toggle icon in the action bar of the conversation thread screen (`GroupedMessagesActivity`) that expands all message items in the list to their full length, and collapses them back to their standard 3-line preview state when clicked again.

## Detailed Proposed Changes

### 1. Adapter (`SmsAdapter.java`)
- Add a new state variable `private boolean isExpandedAll = false;`.
- Add public getter/setter methods:
  - `public void setExpandedAll(boolean expandedAll)`: Updates the state and calls `notifyDataSetChanged()`.
  - `public boolean isExpandedAll()`: Returns the current expansion state.
- In `onBindViewHolder()`:
  - If `isExpandedAll` is true:
    - Set `holder.tvBody.setMaxLines(Integer.MAX_VALUE);`
    - Set `holder.tvBody.setEllipsize(null);`
  - If `isExpandedAll` is false:
    - Set `holder.tvBody.setMaxLines(3);`
    - Set `holder.tvBody.setEllipsize(android.text.TextUtils.TruncateAt.END);`

### 2. Menu Resource (`menu_grouped_messages.xml`)
- Create a new menu file `menu_grouped_messages.xml` under `app/src/main/res/menu/`.
- Add a single item `action_toggle_expand` with default title `"Expand All"` and icon `"@android:drawable/ic_menu_slideshow"`.

### 3. Thread Activity (`GroupedMessagesActivity.java`)
- Implement `onCreateOptionsMenu(Menu menu)`:
  - Inflate `R.menu.menu_grouped_messages`.
  - Initialize the menu item title and icon dynamically based on `adapter.isExpandedAll()`.
- Implement `onOptionsItemSelected(MenuItem item)`:
  - Handle `R.id.action_toggle_expand`:
    - Toggle the adapter's state using `adapter.setExpandedAll(!adapter.isExpandedAll())`.
    - Refresh/invalidate the options menu (`invalidateOptionsMenu()`) to update the icon and title.
