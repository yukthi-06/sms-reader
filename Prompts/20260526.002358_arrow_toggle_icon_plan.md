# Implementation Plan: Update Expand/Collapse Toggle Button to Arrow Icons

We will replace the slideshow and close/cancel icons used for the expand/collapse all messages toggle with universally recognized standard system arrow icons: `@android:drawable/arrow_down_float` and `@android:drawable/arrow_up_float`.

## Detailed Proposed Changes

### 1. Menu Resource (`menu_grouped_messages.xml`)
- Update the icon for `action_toggle_expand` from `@android:drawable/ic_menu_slideshow` to `@android:drawable/arrow_down_float`.

### 2. Thread Activity (`GroupedMessagesActivity.java`)
- Update `onCreateOptionsMenu(Menu menu)`:
  - When the adapter is expanded (action is to collapse), set the icon to `@android:drawable/arrow_up_float` (pointing up to collapse).
  - When the adapter is collapsed (action is to expand), set the icon to `@android:drawable/arrow_down_float` (pointing down to expand).
