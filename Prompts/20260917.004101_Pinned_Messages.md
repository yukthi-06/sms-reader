# Prompt:
for individual messages, give an option to 'PIN' messages.  All the pinned messages should be sitting under a new top row on main screen called 'Pinned Messages'

## Implementation Plan

### Data Layer
- Add methods to `SettingsManager` to get and set a `Set<String>` of `pinned_messages` IDs in the `settings.json`.
- Add a boolean `isPinned`, `isHeader`, and `headerTitle` to `SmsModel.java`.

### UI Layer
- Add an `ImageButton` for pinning next to the delete button in `item_sms.xml`.
- Create `item_header.xml` layout file for the "Pinned Messages" and "Other Messages" headers.

### Logic
- Override `getItemViewType()` in `SmsAdapter.java` to distinguish between normal message items and headers.
- Update `MainActivity.java` to load the pinned IDs when fetching messages.
- Filter the messages into `pinnedList` and `unpinnedList` for the "Individual messages" view.
- Reconstruct the list by adding a "Pinned Messages" header model, then the pinned messages, then an "Other Messages" header model, then the unpinned messages.
