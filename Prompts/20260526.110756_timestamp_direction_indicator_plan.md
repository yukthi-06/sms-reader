# Implementation Plan: Format Message Direction inside Timestamp Parentheses

Instead of displaying the Sent/Received direction on a separate line above the timestamp, we will append it directly next to the timestamp in parentheses (e.g. `(Sent)` in blue or `(Received)` in green). We will hide the sender name view completely to save vertical space.

## Detailed Proposed Changes

### 1. Adapter (`SmsAdapter.java`)
- Modify `onBindViewHolder()`:
  - If `hideSender` is true:
    - Hide `holder.tvSender` completely (`View.GONE`) to save vertical line space.
    - Format `holder.tvTimestamp` using `Html.fromHtml` by appending ` <font color='#3498DB'>(Sent)</font>` or ` <font color='#2ECC71'>(Received)</font>` to the raw timestamp text.
  - If `hideSender` is false:
    - Retain standard `holder.tvSender` rendering and set `holder.tvTimestamp` text normally.
