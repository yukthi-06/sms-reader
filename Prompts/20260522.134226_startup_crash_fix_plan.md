# Implementation Plan - Startup Crash Fix (Android 14+ Compatibility)

We will resolve the startup crash by making the dynamic broadcast receivers compliant with Android 14+ (API 34+) requirements.

---

## 1. Root Cause Identification

Starting in **Android 14 (API 34)**, apps registering dynamic broadcast receivers (using `registerReceiver`) for non-system actions MUST explicitly declare whether the receiver is exported or not exported using the `RECEIVER_EXPORTED` or `RECEIVER_NOT_EXPORTED` flags.
If these flags are not specified, the application immediately throws a `SecurityException` on startup:
`SecurityException: One of RECEIVER_EXPORTED or RECEIVER_NOT_EXPORTED must be specified when a receiver is registered dynamically`.

In our codebase, we dynamically register `smsRefreshReceiver` in:
1. `MainActivity.java` (during `onResume`)
2. `GroupedMessagesActivity.java` (during `onResume`)

Since these receivers are only used internally within our application to communicate refresh triggers, they must be registered as **`RECEIVER_NOT_EXPORTED`**.

---

## 2. Resolution Strategy

We will update both `MainActivity.java` and `GroupedMessagesActivity.java` to dynamically check the platform SDK version. If the app is running on Android 13/14+ (Tiramisu, API 33+), it will register the receiver with the `RECEIVER_NOT_EXPORTED` flag. Otherwise, it will fallback to the standard signature.

### 2.1 Code Change Pattern
We will replace:
```java
registerReceiver(smsRefreshReceiver, new android.content.IntentFilter("com.vypeensoft.smsmanager.REFRESH_SMS"));
```
With a version-safe check:
```java
if (android.os.Build.VERSION.SDK_INT >= android.os.Build.VERSION_CODES.TIRAMISU) {
    registerReceiver(smsRefreshReceiver, new android.content.IntentFilter("com.vypeensoft.smsmanager.REFRESH_SMS"), android.content.Context.RECEIVER_NOT_EXPORTED);
} else {
    registerReceiver(smsRefreshReceiver, new android.content.IntentFilter("com.vypeensoft.smsmanager.REFRESH_SMS"));
}
```

---

## 3. Implementation Steps

1. **Step 1**: Update `onResume()` in `MainActivity.java` to use the version-safe dynamic receiver registration.
2. **Step 2**: Update `onResume()` in `GroupedMessagesActivity.java` to use the version-safe dynamic receiver registration.
