# Prompt:
'Pinned messages' is not a section on main screen.  It is a clickable single row, when clicked, it should open a list of pinned messages

## Implementation Plan

### 1. UI Updates (activity_main.xml)
- Add a static, clickable `MaterialCardView` or `LinearLayout` directly below the search bar in `activity_main.xml`. This row will be labeled "Pinned Messages".
- When clicked, it will launch a new `PinnedMessagesActivity`.

### 2. Logic Rollback (MainActivity.java & SmsAdapter.java)
- Remove the logic that injects "Pinned Messages" and "Other Messages" headers directly into the main list.
- Stop separating pinned messages from the main list. The main list will now just show all messages (or grouped messages) normally.
- Keep the `btnPin` logic in the adapter so users can still pin/unpin messages from the main screen or inside the PinnedMessages view.

### 3. New Activity (PinnedMessagesActivity)
- Create `PinnedMessagesActivity.java` and `activity_pinned_messages.xml`.
- It will load `allSmsList` via `SmsRepository` and filter it strictly to those IDs present in `SettingsManager.getPinnedMessages()`.
- Display the results using the existing `SmsAdapter`.
- Register the new activity in `AndroidManifest.xml`.
